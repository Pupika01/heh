# Маленький сайт-сюрприз

Это полностью статический сайт: HTML, CSS и JavaScript. Никакой базы данных, регистрации или платного хостинга не нужно.

## Как посмотреть на компьютере

1. Распакуй ZIP в отдельную папку.
2. Открой `index.html` в браузере.
3. Проверь кнопки-записки, меню на мобильном размере и кнопку в самом низу страницы.

## Как опубликовать через GitHub Pages

1. Создай новый пустой репозиторий на GitHub.
2. Загрузи в него **все файлы и папку** из этой папки (`index.html`, `styles.css`, `script.js`, `favicon.svg`, `README.md`).
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main`, папку `/ (root)` и нажми **Save**.
6. Через некоторое время GitHub покажет ссылку на опубликованный сайт в разделе Pages.

## Что можно поменять

- Весь текст находится в `index.html` и `script.js`.
- Цвета и оформление — в начале `styles.css`, в блоке `:root`.
- Шрифты загружаются из Google Fonts; если интернета нет, сайт использует системные запасные шрифты.

Сайт адаптирован для телефонов и компьютеров. Все интерактивные элементы работают без сервера.
