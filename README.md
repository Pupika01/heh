# Маленький сюрприз ♡

Романтический интерактивный сайт на русском языке. Он работает как обычная статическая страница и подходит для GitHub Pages.

## Что внутри
- Отдельный анимированный приветственный экран с вопросом «Ты меня любишь?».
- Кнопка «Нет» шуточно уворачивается от курсора и касания; кнопка «Конечно, да» открывает сайт.
- Анимации появления, мягкий параллакс, мерцающие детали, летающие сердечки и плавное появление секций при прокрутке.
- Выбор настроения с персональным сообщением.
- Игра на память: 12 карточек, 6 пар и маленькие послания за совпадения. Награда — полноэкранная анимация виртуального объятия.
- Банка комплиментов со случайными записками.
- Конструктор общего вечера: фильм, видеозвонок или музыка, перекус и атмосфера. Получившееся приглашение можно скопировать.
- Личное письмо и три спрятанных сердечка, которые открывают стилизованный билет-приглашение на следующее свидание.
- Адаптация для телефонов; учтена настройка reduced motion.

## Локальный запуск
Открой `index.html` в браузере. Для шрифтов нужен интернет; без него используются системные шрифты.

## Публикация в GitHub Pages
1. Распакуй архив.
2. Загрузить **содержимое** папки `surprise-final` прямо в корень репозитория (не саму папку).
3. Замени старые `index.html`, `styles.css`, `script.js` и `favicon.svg`.
4. Нажми **Commit changes**.
5. В репозитории открой **Actions** и дождись зелёной галочки публикации Pages.

В корне репозитория должны лежать четыре файла: `index.html`, `styles.css`, `script.js`, `favicon.svg`.


## Музыкальная пауза

На странице добавлен официальный встроенный плеер Spotify с треками Arctic Monkeys: I Wanna Be Yours, 505 и No. 1 Party Anthem. Звук не запускается автоматически: посетитель выбирает песню и нажимает Play в самом плеере. Для работы встроенного плеера нужно подключение к интернету; если он недоступен, есть ссылка на выбранный трек в Spotify.
