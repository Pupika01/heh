# Маленький сюрприз ♡ — версия 8.0

Романтический интерактивный сайт на русском языке. Работает как статическая страница и подходит для GitHub Pages.

## Фоновая музыка

На приветственном экране после нажатия «Конечно, да» запускается загруженный MP3-файл Arctic Monkeys — *I Wanna Be Yours (speed up)*. Музыка играет фоном, а в правом нижнем углу отображается компактная виниловая мини-плашка с названием композиции. Нажатие на неё ставит трек на паузу или продолжает воспроизведение.

Файл находится в `i-wanna-be-yours.mp3` и воспроизводится локально с сайта — SoundCloud и YouTube не используются. Браузеры блокируют автоматическое воспроизведение со звуком до первого действия пользователя, поэтому запуск привязан к нажатию «Конечно, да».

## Что ещё внутри
- Анимированный приветственный экран с вопросом «Ты меня любишь?» и убегающей кнопкой «Нет».
- Плавные анимации, мерцающие детали и летающие сердечки.
- Выбор настроения с персональным сообщением.
- Игра на память: 12 карточек, 6 пар и полноэкранная анимация виртуального объятия.
- Банка комплиментов.
- Конструктор общего онлайн-вечера.
- Личное письмо и спрятанные сердечки с билетом-приглашением.
- Адаптация под телефоны и настройку reduced motion.

## Локальный запуск

Открой `index.html` в браузере. Для веб-шрифтов нужен интернет; MP3-файл загружается с самого сайта.

## Публикация в GitHub Pages

1. Распакуй архив.
2. Загрузи содержимое этой папки прямо в корень репозитория.
3. Загрузи все файлы из архива в корень репозитория, обязательно сохрани папку `assets/music` с MP3-файлом.
4. Нажми **Commit changes**.
5. В разделе **Actions** дождись завершения публикации Pages.
